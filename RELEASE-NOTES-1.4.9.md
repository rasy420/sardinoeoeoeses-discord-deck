# Sardinöööses Soundboard 1.4.9

## Neu am PC
- **Handy verbinden mit Lampe**: Im Knopf oben leuchtet eine Lampe. Gelb heißt, gerade ist kein Handy verbunden. Grün heißt, die Handy-App ist verbunden, ob über den Code oder automatisch wie beim letzten Mal.
- **Neues Kopplungsfenster**: Oben steht jetzt, dass der Code nur bei der ersten Verbindung nötig ist und sich das Handy danach automatisch verbindet. Unten neben OK steht „Warte auf Handyverbindung …“ mit gelber Lampe. Sobald sich das Handy meldet, wird daraus „Handy verbunden“ mit grüner Lampe.
